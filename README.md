# Wise Parenting — Phase 1 Prototype

A responsive visual homepage prototype for **wise parenting**, founded by Alizah Taha — MBBS, Parenting Coach & Educator.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Placeholder content

The logo lockup, portrait, framework image, contact details, program dates/pricing, downloads, and testimonials are intentionally provisional. Replace the logo and framework placeholders only with the original supplied assets; do not recreate or recolor them.

Mock CMS content lives in `src/data/content.ts`. It is kept separate from the presentation components so it can be replaced with an administrator-managed data source in Phase 2 without redesigning the approved interface.

The contact form and resource actions are visual prototype interactions only and do not submit or download files yet.
